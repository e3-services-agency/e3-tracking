# How to evaluate a use case in the Use Case Center

Every use case is accompanied by a pre-defined parametrized evaluation dashboard accessible through the Use Case setup. Each evaluation dashboard is individually tailored to meet the specific requirements of the corresponding use case.

No additional adjustments to the evaluation dashboard are required. Input a few details and hit the yellow “Refresh” button in the upper right corner to view the real-time results.

Find the evaluation dictionary in [this](https://documentation.bloomreach.com/engagement/docs/use-case-evaluation) article.

## Preview for parameters

Every evaluation dashboard within the Use Case Center is parameterized, enabling straightforward data access by inputting minimal details.

The parameters you might need to input to the dashboard are the following:

### Email use case

* Attribution Window for Email Performance - Time between email opened or clicked and purchase. We recommend setting it up to 24h, 48h or 72h
* Attribution Window for Uplift (since AB Split)- Time between AB test split and purchase - used only in uplift calculations. We recommend setting it up to 24h, 48h or 72h.
* Campaign\_name - Name of the campaign that you would like to evaluate
* Action\_name - the name of the email node from the scenario that you would like to evaluate

Learn more about email evaluation in [this](https://documentation.bloomreach.com/engagement/docs/emailing-evaluation) article.

### Banner use case

* Attribution window - Time between banner shown or clicked and purchase. We recommend setting it up to 24h, 48h or 72h. It is also used in uplift calculations to calculate the time between the AB test split and purchase
* Banner\_name - Name of the banner that you would like to evaluate
* Voucher - Voucher code promoted available in the banner

Parameters allow you to filter and interact with the data in dashboards, analyses, and definitions. To learn more about parametrization, please visit [this](https://documentation.bloomreach.com/engagement/docs/analyses#how-to-use-parameters) article.
