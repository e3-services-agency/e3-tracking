## Use case description

Leverage our 2-Way Messaging and Keywords Auto Responses to invite customers to subscribe to you via SMS. Get them to send you a ‘Join’ message, and they are subscribed. The whole process is set up at the project level. This [use case](https://www.bloomreach.com/en/products/engagement/plug-and-play/sms-subscription-via-text-evaluation) is a dashboard that tracks 2-way messaging metrics.

# Use Case Items

With this use case, you’ll get an:

* **Evaluation dashboard**: A comprehensive dashboard provides insights into user behavior, campaign performance, and overall engagement metrics. The dashboard allows you to evaluate the effectiveness of your marketing strategies and make data-driven decisions.
