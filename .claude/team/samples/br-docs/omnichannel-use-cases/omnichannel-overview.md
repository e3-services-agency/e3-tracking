## Use case description

The [Omnichannel overview](https://www.bloomreach.com/en/products/engagement/plug-and-play/omnichannel-overview) use case provides insights into how many customers can be targeted across different channels, which helps determine whether omnichannel campaigns are suitable based on collected data. It also includes logic for Next Best Channel prioritization, identifying the most effective channel for each customer.

### Key features

* Helps in understanding the distribution of customers across various communication channels such as email, SMS, app, website, and more.
* Includes logic for Next Best Channel prioritization, which identifies the most effective channel for each customer.
* Helps in identifying the most effective strategies for customer engagement and retention.

## Use case items

With this use case, you’ll get an:

* WhatsApp segmentation: Adjustable segmentation for customers with WhatsApp consents.
* Web segmentation: Adjustable segmentation fro customer with web personalisation consents.
* Dashboard overview: Provides an overview to get insights. Go through the notes to understand the dashboard.

## How to deploy the use case

After downloading the use case, follow these steps.

### Meet the requirements

Check if the data in your project [meets the requirements](https://documentation.bloomreach.com/engagement/docs/how-to-meet-the-requirements). The Use Case Center lists requirements for each use case during the deployment process.

### Understand the use case logic

The use case provides insights into how many customers can be targeted across different channels, which helps determine whether omnichannel campaigns are suitable based on collected data.

#### Channel insights

This use case helps in understanding the distribution of customers across various communication channels such as email, SMS, app, website, and more. It provides insights into the active subscriber base and revenue generated from these channels.

#### Next best channel prioritization

The use case includes logic for Next Best Channel prioritization, which identifies the most effective channel for each customer. This ensures that the communication is tailored to the customer's preferred channel which enhances engagement and conversion rates.

### Adjust the use case

Now that you understand the use case logic, you can set up the use case according to your needs.

#### Segmentation settings

Access the segmentation of choice and press **Edit** to adjust the [segmentation settings](segmentations).
