# Getting Started

## Overview

The E3 Tracking Implementation Portal is the single source of truth for a client's Bloomreach Engagement tracking plan: events, properties, sources, use cases, identity rules, catalogs and consent categories. It covers intake, data mapping, per-event documentation, automated QA, and export.

This page is a stub while the product is being rebuilt (see the repository [`README`](../../../README.md) and `CLAUDE.md` for the current state). The previous version of this guide described the visual journey builder and workspace header, which have been removed from the product (see decision D-10 in `.claude/team/DECISIONS.md`).
